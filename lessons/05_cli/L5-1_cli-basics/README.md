# L5-1 実践: Copilot CLIを入れて、対話とセッションで使う

ターミナルで動くCopilot CLIを入れます。対話で質問し、セッションを終えてから再開します。最後に、1回だけ頼んで終わる非対話のモードを使います。

## 前提

- L0-2 を終えて、Codespacesを開いていること
- CLIはAIクレジットを使います。1回の依頼ごとに、使ったクレジットが表示されます

## 進め方

| 手順 | やること |
|---|---|
| 1 | Node.jsの版を確かめる |
| 2 | Copilot CLIを入れる |
| 3 | 起動して、リポジトリについて質問する |
| 4 | コマンドを見る |
| 5 | 終了して、セッションを再開する |
| 6 | 非対話のモードで頼む |

### 1. Node.jsの版を確かめる

```bash
node --version
```

`v22` 以上なら使えます（この教材のCodespacesにはNode.js 22が入っています）。

### 2. Copilot CLIを入れる

```bash
npm install -g @github/copilot
copilot --version
```

`GitHub Copilot CLI 1.0.…` のように版が出れば入っています。

### 3. 起動して、リポジトリについて質問する

```bash
copilot
```

Codespacesでは、そのまま使える状態で起動することがあります（サインインを求められたときは、`/login` を送り、画面の指示に従ってブラウザーで承認します）。「GitHub CLI (gh) is not installed.」と出ても、Copilot CLIはそのまま使えます。起動したら、次を送ります。

```text
このリポジトリの app/booklib には、どんなモジュールがありますか？1行ずつ説明してください。
```

### 4. コマンドを見る

入力欄に `/` と打つと、コマンドの一覧が出ます。たとえば次のコマンドがあります。

| コマンド | すること |
|---|---|
| `/model` | 使うモデルを切り替える |
| `/usage` | このセッションで使ったクレジットと、プランの使用量を見る |
| `/init` | このリポジトリ用の `copilot-instructions.md` を作る |
| `/exit` | 今のセッションを閉じる（ほかに開いているセッションが無ければ、CLIを終了する） |

`/usage` を送って、使用量を見ます。

### 5. 終了して、セッションを再開する

1. `/exit` で終了します
2. 次のコマンドで、直前のセッションに戻ります

   ```bash
   copilot --continue
   ```

3. 次を送ると、前の質問の内容を覚えていることが分かります

   ```text
   さっき説明したモジュールのうち、テストが無い関数があるのはどれですか？
   ```

   途中で「Do you want to run this command?」と聞かれたら、コマンドを読んでから `1. Yes` を選びます（tests のファイルを探す、読むだけのコマンドです）

4. `/exit` で終了します


### 6. 非対話のモードで頼む

`-p` を付けると、1回だけ頼んで、答えを出して終わります。スクリプトの中からも使えます。

```bash
copilot -p "data/notes のファイル名を一覧にして、名前をそろえる案を3行で示してください。ファイルは変更しないでください。"
```

最後に、変更した行数（`Changes`）、使ったクレジット（`AI Credits`）、再開のコマンド（`Resume`）が出ます。

続けて、ファイルを作るよう頼んでみます。

```bash
copilot -p "data/notes に memo.txt を作り、「確かめ用」と1行書いてください。"
```

ファイルを作る操作に `Denied, no one to approve` と出て、ファイルは作られません。

> 非対話のモードでは、承認する人がいません。読むだけのコマンド（`ls` など）は動きますが、ファイルを書く・ほかのコマンドを実行するといった操作は、許可しておかないと断られます。許可のしかたはL5-2 で扱います。

### 補足: 特定のセッションに戻る

`copilot --resume` で起動すると、セッションの一覧が出ます。`→` キーでSourceを `Local` にすると、このCodespacesのセッションだけになります。一番上は、いま起動した新しいセッションです。戻りたいセッションを選んで `Enter` で開きます。やめるときは `Esc` を押します（CLIの画面が残ったときは `/exit` で終了します）。

## まとめ

- Copilot CLIは `npm install -g @github/copilot` で入れ、`copilot` で起動します
- `/exit` で終えたセッションは、`copilot --continue` で再開できます
- `-p` を付けると、1回だけ頼んで終わる非対話のモードになります
