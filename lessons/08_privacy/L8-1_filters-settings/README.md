# L8-1 実践: パブリック コード フィルターとエディターの設定

github.comのCopilotの設定で、パブリック コードに一致する提案の扱いを見ます。VS Codeの設定で、特定の言語の補完を止め、提案が出ないときの確かめ方を見ます。

## 前提

- L0-2 を終えて、Codespacesを開いていること

## 進め方

| 手順 | やること |
|---|---|
| 1 | パブリック コードに一致する提案の設定を見る |
| 2 | 許可とブロックの違いを確かめる |
| 3 | Pythonの補完を止める |
| 4 | 補完が出ないことを確かめ、元に戻す |
| 5 | 提案が出ないときの確かめ方 |

### 1. パブリック コードに一致する提案の設定を見る

1. github.comの右上のアイコン → 「Settings」 → 「Copilot」を開きます
2. 「Privacy」の **Suggestions matching public code** を見ます。「Allowed」（許可）か「Blocked」（ブロック）を選べます

> 組織からCopilotを受けている場合は、ここを自分で変えられないことがあります。組織の管理者が決めます。

### 2. 許可とブロックの違いを確かめる

| 設定 | 提案の扱い |
|---|---|
| 「Blocked」 | 公開されているコードと一致する提案を出しません |
| 「Allowed」 | 一致する提案も出します。そのとき、一致したコードの参照（どのリポジトリの、どのライセンスのコードか）を確かめられます |

この教材では設定を変えません。

### 3. Pythonの補完を止める

1. CodespacesでCtrl+, を押して、設定を開きます
2. 検索欄に `github.copilot.enable` と入れます
3. 「GitHub › Copilot: Enable」の「項目の追加」を押し、項目に `python`、値に `false` を入れて「OK」を押します

### 4. 補完が出ないことを確かめ、元に戻す

1. `app/booklib/stats.py` を開き、コメントの下で `def ` と打ちます。灰色の提案が出ないことを確かめます（Chatは使えます）
2. 設定に戻り、`python` の行の × を押して消します。もう一度 `def ` と打つと、提案が出ます

> 補完を止めていても、Alt+\\ を押すと、その場で提案を出せます。

### 5. 提案が出ないときの確かめ方

提案が出ないときは、次の順に確かめます。

1. サインインしているか（左下のアカウントと、状態バーのCopilotのアイコン）
2. この言語の補完を止めていないか（手順3の設定）
3. ネットワークにつながっているか
4. 組織の設定で、そのファイルがCopilotの対象から外されていないか（コンテンツ除外。第8章の座学）

## まとめ

- パブリック コードに一致する提案は、個人の設定で許可かブロックを選べます
- `github.copilot.enable` で、言語ごとに補完を止められます
- 提案が出ないときは、サインイン・設定・ネットワーク・除外の順に確かめます
