# L4-1 実践: インラインの提案と次の編集候補

コメントと関数名から、Copilotに関数の中身を提案してもらいます。提案を受け入れたら、テストを走らせて確かめます。最後に、1か所を変えたときに、関連する場所への次の編集候補が出ることを見ます。

## 前提

- L0-2 を終えて、Codespacesを開いていること
- インラインの提案は、有料プランではAIクレジットを使いません（Freeは月の回数に上限があります）

## 進め方

| 手順 | やること |
|---|---|
| 1 | レッスン用のブランチを作る |
| 2 | テストが通らないことを確かめる |
| 3 | コメントの下で提案を出す |
| 4 | 提案を受け入れる・単語ごとに受け入れる・別の候補を見る |
| 5 | 2つ目の関数も提案で書く |
| 6 | テストで確かめる |
| 7 | 次の編集候補を見る |

### 1. レッスン用のブランチを作る

```bash
git switch main && git switch -c lesson/l4-1
```

### 2. テストが通らないことを確かめる

```bash
pytest -q lessons/04_ide/L4-1_inline
```

`app/booklib/stats.py` には、まだコメントしかありません。関数が無いので、エラーになります。

### 3. コメントの下で提案を出す

1. `app/booklib/stats.py` を開きます
2. `# 著者ごとの冊数を数えて…` の行の末尾をクリックし、Enterを押します
3. `def ` と打つと、続きが薄い灰色の文字で出ます（ゴースト テキスト）。たとえば `count_by_author(books):` のように出ます

### 4. 提案を受け入れる・単語ごとに受け入れる・別の候補を見る

- Tab: 提案を受け入れます
- Ctrl+→（Macは ⌘+→）: 提案を単語ごとに受け入れます
- Alt+]・Alt+[: 別の候補に切り替えます（候補が1つのときは変わりません）
- Esc: 提案を捨てます

灰色の文字の上にマウスを置くと、小さなツールバーが出ます。`1/1` は候補の数で、「承諾」（Tab）と「単語を採用する」（Ctrl+→）のキーも出ます。

関数名を受け入れたらEnterを押し、次の行の提案もTabで受け入れていきます。

> 提案が、カーソルの位置でなく、少し離れた行に出ることがあります。行番号の横に矢印の印が出て、入る内容が枠で出ます。これは次の編集候補（手順7）です。Tabで候補の場所へ移り、もう一度Tabで受け入れます。

### 5. 2つ目の関数も提案で書く

`# 出版年の古い順に並べた書名のリストを返す関数 …` の下でも、同じように提案を出して受け入れます。1つ目の関数を書き終えたところで、2つ目の関数が次の編集候補として先に出ることもあります。終わったらCtrl+Sで保存します。

### 6. テストで確かめる

```bash
pytest -q lessons/04_ide/L4-1_inline
```

`3 passed` なら、提案を受け入れてよかったと判断できます。通らなかったときは、失敗したテストの名前を見て、提案を直すか捨てて出し直します。

たとえば、`1 failed, 2 passed` と出て、`AttributeError: 'Book' object has no attribute 'year'` と表示されることがあります。提案が、`Book` に無い `year` を使ったためです。`app/booklib/models.py` を開くと、出版年は `published` です。`year` を `published` に直して保存し、もう一度テストを走らせます。

### 7. 次の編集候補を見る

1. `count_by_author` の引数の名前 `books` を `items` に変えます
2. 少し待つと、同じ関数の中で `books` を使っている行に、次の編集候補が出ます（行番号の横に矢印の印が出て、`books` を `items` に置き換える候補が小さな枠で出ます）
3. Tabで候補の場所へ移り、もう一度Tabで受け入れます。受け入れないときはEscを押します

> 次の編集候補が出ないときは、少し待つか、最後の1文字を消して打ち直します。それでも出ないときは、設定（Ctrl+,）で `github.copilot.nextEditSuggestions.enabled` が有効かを確かめます。

## 後片付け

```bash
git checkout -- app/booklib/stats.py && git switch main && git branch -D lesson/l4-1
```

## まとめ

- コメントと関数名が、提案の手がかりになります
- 提案は、受け入れて初めてコードに入ります。受け入れる前に読み、受け入れたらテストで確かめます
- 1か所を変えると、関連する場所の次の編集候補が出ます
