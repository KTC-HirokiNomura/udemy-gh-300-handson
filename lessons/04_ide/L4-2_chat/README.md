# L4-2 実践: Copilot Chatの使い方

Chatビューで、コードの説明・ファイルの指定・スラッシュ コマンド・Planを試します。答えにフィードバックを付け、モデルの選択の画面も見ます。

## 前提

- L0-2 を終えて、Codespacesを開いていること
- Chatの答えはAIクレジットを使います（答えの下に、使ったクレジットが出ます）

## 進め方

| 手順 | やること |
|---|---|
| 1 | レッスン用のブランチを作り、Chatを準備する |
| 2 | Askでコードの説明を頼む |
| 3 | `#` でファイルを指定して聞き直す |
| 4 | スラッシュ コマンドを使う |
| 5 | Planで変更の計画を作る |
| 6 | 答えにフィードバックを付ける |
| 7 | モデルの選択の画面を見る |

### 1. レッスン用のブランチを作り、Chatを準備する

```bash
git switch main && git switch -c lesson/l4-2
```

1. Ctrl+Alt+IでChatを開き、右上の「＋」（新しいチャット）を押します
2. 入力欄の下の切り替えを「ローカル」にします
3. 入力欄の左下のモードを「Ask」にします

### 2. Askでコードの説明を頼む

`app/booklib/loans.py` を開いてから、次を送ります。

```text
このファイルの LoanService は何をするクラスですか？メソッドごとに1行で説明してください。
```

開いているファイルが、入力欄の上に添付として出ています。Copilotはこのファイルを手がかりに答えます。

### 3. `#` でファイルを指定して聞き直す

エディターのタブをすべて閉じてから、次を送ります。

```text
#file:app/booklib/loans.py と #file:docs/design.md を読んで、設計メモの貸出の決まりのうち、コードで守られていないものを挙げてください。
```

設計メモに書かれた「貸出中の本は貸さない」「存在しない蔵書IDは断る」が、`borrow` で守られていないことが挙がります。`#` で渡したファイルによって、答えが変わります。

### 4. スラッシュ コマンドを使う

入力欄に `/` と打つと、使えるコマンドの一覧が出ます。たとえば次のコマンドがあります。

| コマンド | すること |
|---|---|
| `/explain` | 選んだコードを説明する |
| `/fix` | 選んだコードの問題を直す案を出す |
| `/tests` | 選んだコードのテストを作る |
| `/new` | 新しいプロジェクトのひな形を作る |
| `/compact` | これまでの会話を短くまとめて、続きを話す |

`app/booklib/report.py` の `format_overdue` 関数を選択してから、次を送ります。

```text
/tests
```

テストのコードが出ます。ここでは読むだけにします（ファイルには入れません）。

### 5. Planで変更の計画を作る

1. 入力欄の左下のモードを「Plan」にします
2. 次を送ります

   ```text
   loans.py の borrow に、設計メモの貸出の決まり（貸出中の本と、存在しない蔵書 ID を断る）を入れる計画を立ててください。
   ```

3. 「計画」として、手順・検証・対象外が出ます。Planはコードを変えません。計画を読んで、足りない点があれば言葉で直してもらいます
4. 計画の下に「Start Implementation」（この計画で実装を始める）などのボタンが出ます。ここでは押しません（実装はエージェント モードで行います。L4-3）

### 6. 答えにフィードバックを付ける

答えの下にある、親指を上に向けたボタンと下に向けたボタンで、答えがよかったかを送れます。答えの下には、かかった時間・使ったモデル・使ったクレジットも出ます。

### 7. モデルの選択の画面を見る

入力欄の下の「Auto」を押すと、モデルの一覧が出ます。「Auto」は、頼んだ内容に合わせてモデルを選びます（答えの上に、どのモデルに振り分けたかが出ます）。ここでは選ぶだけにして、Autoに戻します。

## 後片付け

```bash
git switch main && git branch -D lesson/l4-2
```

## まとめ

- Askは答えるだけで、コードを変えません。Planは計画を立てるだけで、コードを変えません
- `#` で渡したファイルが、答えの手がかりになります
- スラッシュ コマンドで、よくある依頼を短く頼めます
