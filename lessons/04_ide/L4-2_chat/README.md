# L4-2 実践: Copilot Chatの使い方

Chatビューで、コードの説明・ファイルの指定・スラッシュ コマンド・Planを試します。答えにフィードバックを付け、モデルの選択の画面も見ます。

## 前提

- L0-2 を終えて、Codespacesを開いていること
- Chatの答えはAIクレジットを使います（答えの下に、使ったクレジットが出ます）

## 進め方

| 手順 | やること |
|---|---|
| 1 | レッスン用のブランチを作り、Chatを準備する |
| 2 | Askでコードの説明を頼む |
| 3 | `#` でファイルを指定して聞き直す |
| 4 | スラッシュ コマンドを使う |
| 5 | Planで変更の計画を作る |
| 6 | 答えにフィードバックを付ける |
| 7 | モデルの選択の画面を見る |

### 1. レッスン用のブランチを作り、Chatを準備する

```bash
git switch main && git switch -c lesson/l4-2
```

1. Ctrl+Alt+IでChatを開き、右上の「＋」（新しいチャット）を押します
2. 入力欄のさらに下にある切り替え（最初は「Copilot」と出ています）を「ローカル」にします
3. 入力欄の左下のモードを「Ask」にします

### 2. Askでコードの説明を頼む

`app/booklib/loans.py` を開いてから、次を送ります。

```text
このファイルの LoanService は何をするクラスですか？メソッドごとに1行で説明してください。
```

開いているファイルが、入力欄の上に添付として出ています。Copilotはこのファイルを手がかりに答えます。

### 3. `#` でファイルを指定して聞き直す

エディターのタブをすべて閉じます（入力欄の上の添付も消えます）。そのうえで、次の順に入力します。

1. 入力欄に `#loans` と打つと、候補の一覧に `loans.py` が出ます。選ぶと、入力欄にファイルの札が入ります
2. 続けて `#design` と打ち、候補の `design.md` を選びます
3. 札のあとに次の文を入れて、送ります

```text
この2つのファイルを読んで、設計メモの貸出の決まりのうち、コードで守られていないものを挙げてください。
```

設計メモに書かれた「貸出中の本は貸さない」「存在しない蔵書IDは断る」が、`borrow` で守られていないことが挙がります。`#` で渡すと、読んでほしいファイルを確実に渡せます。答えは、設計メモと見比べて確かめます。

### 4. スラッシュ コマンドを使う

入力欄に `/` と打つと、使えるコマンドの一覧が出ます。たとえば次のコマンドがあります。

| コマンド | すること |
|---|---|
| `/explain` | 選んだコードを説明する |
| `/fix` | 選んだコードの問題を直す案を出す |
| `/tests` | 選んだコードのテストを作る |
| `/new` | 新しいプロジェクトのひな形を作る |
| `/compact` | これまでの会話を短くまとめて、続きを話す |

`app/booklib/report.py` を開いてから、次を送ります（関数を選択してから `/tests` だけを送っても同じです）。

```text
/tests format_overdue
```

テストのコードが出ます。ここでは読むだけにします（ファイルには入れません）。

### 5. Planで変更の計画を作る

1. 入力欄の左下のモードを「Plan」にします
2. 次を送ります

   ```text
   loans.py の borrow に、設計メモの貸出の決まり（貸出中の本と、存在しない蔵書 ID を断る）を入れる計画を立ててください。
   ```

3. 計画として、手順や、変える範囲などが出ます。Planはコードを変えません。計画を読んで、足りない点があれば言葉で直してもらいます
4. 計画の下に「Start Implementation」（この計画で実装を始める）などのボタンが出ます。ここでは押しません（実装はエージェント モードで行います。L4-3）

### 6. 答えにフィードバックを付ける

答えの下にある、親指を上に向けたボタンと下に向けたボタンで、答えがよかったかを送れます。答えにマウスを置くと、答えの下に、時刻・使ったモデル・使ったクレジットも出ます（かかった時間は、答えの上の「Completed … in …」に出ます）。

### 7. モデルの選択の画面を見る

入力欄の中の、モードの右にある「Auto」を押すと、モデルの一覧が出ます。「Auto」は、頼んだ内容に合わせてモデルを選びます（どのモデルが答えたかは、手順6のとおり、答えにマウスを置くと右に出ます）。ここでは見るだけにして、Autoのままにします。

## 後片付け

```bash
git switch main && git branch -D lesson/l4-2
```

## まとめ

- Askは答えるだけで、コードを変えません。Planは計画を立てるだけで、コードを変えません
- `#` で渡したファイルが、答えの手がかりになります
- スラッシュ コマンドで、よくある依頼を短く頼めます
