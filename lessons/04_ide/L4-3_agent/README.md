# L4-3 実践: エージェント モードとサブエージェント、セッションの管理

エージェント モードに、複数のファイルにまたがる変更（機能の追加とテスト）を頼みます。コマンドの実行の承認、変更の確認と取り消し、サブエージェント、セッションの一覧を見ます。

## 前提

- L0-2 を終えて、Codespacesを開いていること
- エージェントは何手順も動くので、Askより多くのAIクレジットを使うことがあります

## 進め方

| 手順 | やること |
|---|---|
| 1 | レッスン用のブランチを作り、Agentを選ぶ |
| 2 | 機能の追加を頼む |
| 3 | コマンドの実行を承認する |
| 4 | 変更を確かめ、受け入れるか戻すかを決める |
| 5 | サブエージェントに調べものを任せる |
| 6 | セッションの一覧を見る |
| 7 | テストで確かめる |

### 1. レッスン用のブランチを作り、Agentを選ぶ

```bash
git switch main && git switch -c lesson/l4-3
```

Chatで新しいチャットを開き、入力欄のさらに下の切り替えを「ローカル」に、モードを「Agent」にします。

### 2. 機能の追加を頼む

```text
app/booklib/catalog.py の search に、結果を出版年の新しい順に並べ替える引数 newest_first（既定は False）を足してください。tests/test_catalog.py にテストも足して、pytest で確かめてください。
```

エージェントは、ファイルを読み、編集し、テストを走らせるところまで、自分で手順を進めます。

### 3. コマンドの実行を承認する

途中で「bashコマンドを実行しますか?」「テストの実行を許可しますか?」と聞かれます。コマンドの下には、そのコマンドが何をするかの短い説明が出ます。ファイルの編集は、確認なしで進むことがあります。編集は、手順4で見直します。

- 説明は短いので、コマンドそのものを読んでから「許可」を押します。分からないコマンドは「スキップ」します
- 「テストの実行を許可しますか?」では、ボタンが「このセッションで許可する」になっています。横の ▾ を押し、「一度のみ許可」を選びます。▾ には「このワークスペースで許可する」「常に許可」もあります。範囲を広げると、そのツールは次から聞かれずに動くので、ここでは1回ずつ許可します
- Pythonの拡張機能が入れるツール（pylance mcp server）の確認が出ることがあります。この実践では使わないので「スキップ」します

### 4. 変更を確かめ、受け入れるか戻すかを決める

終わると、入力欄の上に「2個のファイルが変更されました」と出ます。

1. 左の「>」を押すと、変更したファイルの一覧が開きます。ファイル名を押すと、エディターに変更の差分が出ます。読んで、頼んだとおりかを確かめます
2. よければ、一覧の上の「保持」、やめるなら「元に戻す」を押します。一覧の行の右のボタンで、ファイルごとに選ぶこともできます。エージェントの編集は、すでにファイルに保存されています。「保持」は変更を受け入れ、「元に戻す」は変更を取り消します

### 5. サブエージェントに調べものを任せる

```text
サブエージェントに、tests/ の既存のテストの書き方（fixture の使い方・名前の付け方）を調べさせて、結果を3行で要約してください。ファイルは変更しないでください。
```

「1 subagent running」と出て、サブエージェントが別のコンテキストで調べ、要約だけを返します。調べものの途中の内容が、元のエージェントのコンテキストに入らないのが利点です。

「1 subagent running」が出ないときは、入力欄のツールの設定（Configure Tools）で、サブエージェントのツール（Run Subagent）が選ばれているかを確かめます。

### 6. セッションの一覧を見る

Chatの左上の「←」を押すと、セッションの一覧に戻ります。いまのセッションと、前のセッションが並び、変更した行の数と、いつのものか（何分前・何時間前）が出ます。セッションを押すと、その会話に戻れます。

### 7. テストで確かめる

```bash
pytest -q
```

手順4で元に戻していなければ、足したテストを含めて全部通ります。

## 後片付け

```bash
git checkout -- . && git switch main && git branch -D lesson/l4-3
```

## まとめ

- エージェント モードは、読む・編集する・コマンドを実行するを、自分で続けて進めます
- コマンドは、承認する前に読みます。変更は、差分を読んでから受け入れます
- サブエージェントは調べものを別のコンテキストで行い、結果だけを返します
