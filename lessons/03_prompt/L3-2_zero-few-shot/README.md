# L3-2 実践: ゼロショットとフューショットを比べる

日付の文字列をそろえる関数 `normalize_date` を、Copilotに2回書いてもらいます。1回目は例を付けずに頼み（ゼロショット）、2回目は例を付けて頼みます（フューショット）。確かめるスクリプトで、12件のうち何件そろえられたかを比べます。

## 前提

- L0-2 を終えて、Codespacesを開いていること

## 進め方

| 手順 | やること |
|---|---|
| 1 | レッスン用のブランチを作る |
| 2 | いまの件数を確かめる |
| 3 | ゼロショットで頼む |
| 4 | 件数を確かめる |
| 5 | 元に戻して、フューショットで頼む |
| 6 | 件数を確かめて、比べる |
| 7 | 結果を判断する |

### 1. レッスン用のブランチを作る

```bash
git switch main && git switch -c lesson/l3-2
```

### 2. いまの件数を確かめる

```bash
python lessons/03_prompt/L3-2_zero-few-shot/check_dates.py
```

`normalize_date` はまだ中身が無いので、`12件中 0件 通りました` と出ます。

### 3. ゼロショットで頼む

1. `app/booklib/dates.py` を開きます
2. `raise NotImplementedError` の行にカーソルを置き、Ctrl+Iを押します（エディターの中に入力欄が出ます。インライン チャットです）
3. 次の文を貼り付けて、Enterを押します

   ```text
   normalize_date 関数を実装してください。
   ```

4. 提案のコードが緑で出たら、「保持」（Keep）を押し、Ctrl+Sで保存します

### 4. 件数を確かめる

```bash
python lessons/03_prompt/L3-2_zero-few-shot/check_dates.py
```

たとえば `12件中 2件 通りました` のように出ます。`2024-01-05` の形のほかは、ほとんど通りません。どの形の日付を受け取るのかを、Copilotは知らないからです。

### 5. 元に戻して、フューショットで頼む

1. 書いてもらったコードを捨てます

   ```bash
   git checkout -- app/booklib/dates.py
   ```

2. もう一度 `raise NotImplementedError` の行でCtrl+Iを押し、例を付けた次の文を貼り付けてEnterを押します

   ```text
   normalize_date 関数を実装してください。例: 「2024/1/5」→「2024-01-05」、「2023年12月31日」→「2023-12-31」、「令和元年5月1日」→「2019-05-01」、「H30.12.1」→「2018-12-01」
   ```

3. 「保持」を押し、Ctrl+Sで保存します（提案が `import` の行と本体のように2か所に分かれたときは、両方で「保持」を押します）

### 6. 件数を確かめて、比べる

```bash
python lessons/03_prompt/L3-2_zero-few-shot/check_dates.py
```

たとえば `12件中 11件 通りました` のように、ゼロショットより増えます。例に無い形（`2024.1.5` など）は、落ちることがあります。

### 7. 結果を判断する

- 例は、答えの形と範囲をCopilotに伝えます。例に無い形まで扱ってほしいときは、例を足すか、言葉で書き足します
- 通らなかった件は、そのまま受け入れずに、例を足して頼み直すか、自分で直します

> **Chatビューで同じことを頼むと、差が出にくくなります。** Chatのエージェントは、ワークスペースの中のテストや、この確かめるスクリプトを探して読むことがあるからです。インライン チャットは、開いているファイルを中心に答えます。

## 後片付け

```bash
git checkout -- app/booklib/dates.py && git switch main && git branch -D lesson/l3-2
```

## まとめ

- ゼロショットは指示だけで頼み、フューショットは例を付けて頼みます
- 例を付けると、答えの形がそろい、通る件数が増えました
- 答えは毎回変わります。件数は、確かめるスクリプトで数えて判断します
